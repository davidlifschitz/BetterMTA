# Production Checklist

## Product
- [ ] All MVP acceptance criteria pass.
- [ ] Impossible constraints return useful alternatives.
- [ ] Data freshness is visible.
- [ ] Feedback is available on every itinerary.

## Routing
- [ ] Golden benchmark reviewed.
- [ ] Required-line coverage semantics tested.
- [ ] Feed snapshot replay is reproducible.
- [ ] Baseline comparison is documented.

## Engineering
- [ ] CI blocks failing tests, lint, typecheck, and build.
- [ ] Preview environment exists.
- [ ] Rollback procedure tested.
- [ ] Rate limits configured.

## Operations
- [ ] Logs, metrics, traces, and errors are observable.
- [ ] Synthetic route probes alert on failures.
- [ ] Feed staleness alert exists.
- [ ] Incident owner and playbook exist.

## Privacy and legal
- [ ] Location retention minimized.
- [ ] Preference-learning consent stored.
- [ ] Privacy policy published.
- [ ] Data-source terms reviewed.

## Launch
- [ ] Mobile usability test passes.
- [ ] Accessibility audit passes.
- [ ] Support and correction process documented.
- [ ] Public-beta limitations are explicit.
